== hidden install button ==
#pwa-install-btn ships with the hidden attribute and is revealed only when
beforeinstallprompt fires. `hidden` is UA-origin display:none, so an author
`display` on .foot-link-btn overrides it.

Headless Chromium fires beforeinstallprompt, so the attribute has to be set
back on to observe the state a real iOS Safari or Firefox visitor gets.

  author display, hidden set    display=flex  height=44px  rendered=true
  [hidden] reset, hidden set    display=none  height=0     rendered=false
  [hidden] reset, hidden off    display=flex  height=44px  rendered=true

.mmr-share-btn[hidden] carries the same reset 64 lines below.

== progress readout ==
status_payload.py reports elapsed as unbounded wall-clock since segment
start. renderProgress clamped the bar but wrote the elapsed text raw.

  progress / duration    elapsed    total
  3 / 180                0:03       3:00
  9 / 4                  0:04       0:04    (within grace, clamped)
  204 / 4                —          —       (was 3:24 / 0:04)

The 0:04 case is the 4.44s packaged continuity clip, web/streamer.py.

Display only. status_payload.py is unchanged; it still computes progress
with no bound against duration.

The readout sits inside <div class="mmr-np-progress" aria-hidden="true">,
listener.html, so no assistive technology reads either form.
